# Spesifikasi Layar: Akun (/admin/akun)

## Tujuan
Halaman manajemen akun administrator dan perubahan password.

## Komponen & Perilaku
- Ganti password sendiri (membutuhkan password lama, min. 10 karakter).
- Kelola admin: daftar admin, tambah admin baru, nonaktifkan admin (tidak boleh menonaktifkan diri sendiri).
