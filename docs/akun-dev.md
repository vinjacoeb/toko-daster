# Akun Admin Dev (Lokal)

Untuk pengujian lokal, seeder mendaftarkan satu akun administrator dengan detail berikut:

- **Nama**: Administrator
- **Email**: `admin@example.com`
- **Password**: `password123`

Harap ubah kredensial ini atau tambahkan akun baru melalui menu admin jika diperlukan. Jangan pernah menggunakan kredensial ini di lingkungan produksi.
