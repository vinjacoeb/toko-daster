# Brief: Frontend Developer

## Pekerjaan
- Membangun antarmuka dengan React + Inertia + Tailwind.
- Implementasi halaman publik dan dashboard admin.
- Komponen dasar (tombol, input, kartu, swatches).

## Bacaan
- PRD.md Bagian 5, 6, 10.
- `design.md` (Warna, Tipografi, Grid, Komponen).
- `docs/design/*.md` (Spesifikasi UI/UX).

## Output
- Kode frontend (`resources/js/`).
- Komponen JSX yang terpisah.

## Definition of Done
- Tampilan sesuai `design.md`.
- Interaksi publik (Pesan via WA) berfungsi.
- Admin dashboard berfungsi dan menampilkan data dengan benar.
- Responsif, aksesibel, performa sesuai target (LCP, Lighthouse).

## Catatan
- Perhatikan impor `React` di setiap komponen.
- Gunakan placeholder untuk produk tanpa foto.
- Jangan ada teks "lorem ipsum" atau teks stok.
- v1.1: Halaman wajib bebas teks placeholder (gunakan data DB via props). Cetak laporan via `window.print()`. Impor komponen persis case-sensitive tanpa eager glob. Carousel maks 5 slide tanpa autoplay.
