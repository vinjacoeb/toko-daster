# Brief: QA

## Pekerjaan
- Membuat test plan dan matriks risiko.
- Melakukan pengujian terhadap implementasi (publik dan admin).
- Membuat laporan pengujian.

## Bacaan
- PRD.md (semua bagian).
- `design.md`.

## Output
- `docs/qa-test-plan.md`.
- `docs/qa-report.md`.

## Definition of Done
- Semua fitur P0 teruji dan dilaporkan.
- Laporan Go/No-Go yang jelas.

## Catatan
- Uji lewat HTTP ke server pemilik (`http://127.0.0.1:8000`).
- Tulis "Belum diuji" untuk hal yang tidak dijalankan atau butuh browser, jangan menulis "lulus".
